# 玄弈 · 极限五子棋

[在线游玩](https://Christy-Zha.github.io/obsidian-gomoku/)

15 × 15 自由规则五子棋，挑战在浏览器本机运行的多步搜索 AI。无安装、无依赖、无 API 密钥，也可以下载 `index.html` 后直接打开离线游玩。

- 默认「深渊」难度，单次思考预算约 8 秒；大师约 3 秒，高手约 1 秒。
- 支持换先后手、悔棋、提示、显示手数和落子音效。
- 支持点击、触控与键盘操作。方向键选点，回车或空格落子。
- 当前棋局自动保存在浏览器本地。不同设备、浏览器、网址及离线文件的存档相互独立。
- 横、竖或斜向连成五子及以上获胜，无禁手。

AI 使用候选点筛选、棋形与组合威胁评分、迭代加深、Alpha-Beta 剪枝、置换表和强制防守延伸。实际搜索深度与棋力随设备和局面变化，并非不可战胜。

## 本地开发

需要 Node.js，游戏运行本身不需要 Node.js。

```sh
node build.cjs
node test.cjs
node test-ui.cjs
```

修改 `template.html`、`style.css`、`engine.js` 或 `app.js` 后运行构建并提交生成的 `index.html`。GitHub Pages 从 `main` 分支根目录发布。

20 项棋力及规则检查、10 项模拟 DOM 对局状态检查已通过。模拟 DOM 不替代浏览器验收；真实浏览器画面和移动触控尚未实测。
